Project Structure

config/ controller/ dto/ request/ response/ entity/ enums/ repository/
security/ service/

Security Classes - SecurityConfig - JwtService -
JwtAuthenticationFilter - CustomUserDetailsService - UserPrincipal -
AuthenticationFacade

Repositories - UserRepository - TransactionRepository

Entities - User - Transaction

Flow

Register ↓ User saved (password encrypted) ↓ Login ↓ JWT Generated ↓
Frontend stores JWT ↓ JWT sent in Authorization header ↓
JwtAuthenticationFilter validates token ↓ Authenticated user available ↓
Transaction saved for logged-in user

Frontend Requirements 1. Register page 2. Login page 3. Store JWT after
login 4. Send JWT in Authorization header: Bearer 5. Add Transaction
page 6. Transaction History page

Next Backend Modules - Loan Application - Risk Assessment - Admin
Dashboard - Loan Approval - Loan Risk Prediction Engine

Notes - DTOs are used between frontend and backend. - Entities are
mapped to database tables. - Never return entities directly to the
frontend. - Passwords are stored using BCrypt. - JWT validity: 24
hours. - Transaction APIs require a valid JWT.
